# blender-circuits-mcp

MCP server for **Circuit Lab**: it forwards AI tool calls to the Circuit Lab add-on running inside Blender
(TCP, default `127.0.0.1:9877`). See the [project README](../README.md) for installation of the add-on,
client configuration and the full tool reference.

```bash
pip install .
blender-circuits-mcp        # stdio MCP server
```
